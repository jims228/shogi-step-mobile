# カリキュラム再設計 v4

## 設計方針

- **テーマ別 × レベル別**の混合構成
- 1レッスン = 4-6ステップ（2-5分）
- 1日1-3レッスンで**6ヶ月以上**継続可能
- **飛び級**: U0診断テストで開始ユニットを決定 + 各セクション末にスキップテスト
- レッスン種類: 学習 / 詰将棋 / 次の一手 / 定跡紹介
- 詰将棋: 1手詰め100問 + 3手詰め100問 + 5手詰め（将来追加）

## レベル構成

| レベル | セクション | 対象 | 内容 |
|--------|----------|------|------|
| **入門** | S1-S3 | 完全初心者 | 駒の動き、ルール、基本操作 |
| **初級** | S4-S7 | ルールは知っている | 詰み、受け、駒の価値、簡単な手筋 |
| **中級** | S8-S11 | 対局経験あり | 囲い、序盤、中盤、実戦形の詰将棋 |
| **上級** | S12-S14 | 級位者 | 定跡、次の一手、5手詰め、応用手筋 |

## 飛び級の仕組み

```
U0 診断テスト（6問）
├── 0-1問正解 → S1（入門）から開始
├── 2-3問正解 → S4（初級）から開始
├── 4-5問正解 → S8（中級）から開始
└── 6問正解 → S12（上級）から開始

各セクション末に「スキップテスト」
└── 合格 → 次のセクションへジャンプ可能
└── 不合格 → 通常通り進む
```
