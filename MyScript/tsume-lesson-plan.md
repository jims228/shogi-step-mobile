# 詰将棋レッスン配置案 v3

## 設計方針
- 1レッスン = **4問**
- 詰みの概念（U4）を学ぶ**前**に1手詰めは出さない
- U4で詰みを学んだ後から1手詰め開始、その後3手詰めを混ぜていく
- 各駒を学んだ「後」のUnitで、その駒の詰将棋を配置
- 駒別10問 = 2.5レッスン → 2レッスン(4問×2=8問) + 残2問は応用に混ぜる
- 「復習2問」は使わない（復習機能は別途実装予定）
