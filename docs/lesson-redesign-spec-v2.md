# 将棋ステップ レッスン設計仕様書 v2

## コンセプト

> Duolingoの入りやすさで始まり、将棋教室の納得感で終わるアプリ

- 初心者が怖がらずに始められる
- 続けられる
- 実際の対局で「前より分かる」を感じる

---

## 1. レッスン種別

| 種別 | コード | 内容 | 1回の長さ |
|---|---|---|---|
| **概念導入** | `learn` | コーチが概念を見せる。必ず操作付き（タップ/移動で確認） | 2〜3分 |
| **ガイド付き** | `guided_move` | 指示に従って駒を動かす。正解は1つ、ヒント付き | 2〜3分 |
| **自力発見** | `find_move` | ヒントなしで最善手を探す | 3〜4分 |
| **比較判断** | `compare` | 2〜3候補を見せて「どれが良いか＋なぜか」を問う。**Why step** | 3〜4分 |
| **復習** | `review` | 過去のミス＋弱点スキルを混合出題 | 3〜5分 |
| **ガイド対局** | `coached_game` | コーチが途中で止めてアドバイスする短い対局 | 5〜10分 |
| **振り返り** | `post_game_reflection` | 対局後に「良かった手」「危なかった手」「次の約束」の3カード | 1〜2分 |

---

## 2. コース構造（プレイヤーの仕事順）

### Section 0: はじめる前に（初期診断）

**目標**: レベルを判定し、適切なスタート地点を決める

- 90秒の診断テスト（5問）
- 3択: 「まったく初めて」「ルールは知ってる」「少し指せる」
- 結果に応じてSection 1〜4のどこから始めるか決定

### Section 1: 勝ち負けを知る

**Can-do**: 王手が何かわかる。王手をかけられる。王手を防げる。

|---|---|---|---|
| 1 | learn | 将棋ってどんなゲーム？ | 盤面タップで駒を確認。勝利条件を理解 |
| 2 | learn | 歩と金の動き | 歩の前進、金の6方向をタップ＋移動で確認 |
| 3 | guided_move | 歩で進んでみよう | 歩を動かす。取る。2〜3問 |
| 4 | guided_move | 金で守ってみよう | 金で王を守る位置に動かす |
| 5 | learn | 王手ってなに？ | 王手の概念。王手をタップで見つける |
| 6 | find_move | 王手をかけてみよう | 金で王手をかけるパズル |
| 7 | compare | 王手？それとも駒を取る？ | 2つの候補を比較。**Why: 王手は必ず受けなきゃいけない** |

## 3. 1レッスンの標準テンプレート

```
ステップ1: 今日の目標（coach_text表示 + 盤面タップで確認）
ステップ2: ガイド付き確認（guided_move: 指示に従って動かす）
ステップ3: 自力で1回やる（find_move: ヒントなし）
ステップ4: Why step（compare: 2候補を比較、なぜこっちが良いか）
ステップ5: もう1回自力（find_move: 別の局面で同じスキル）
ステップ6: 簡単な成功体験（guided_move: 確実に正解できる問題）

※ ミスした問題はステップ6の後に自動追加
```

### Why step（compare）の設計

```
表示: 盤面 + 2〜3つの候補手を選択肢として表示
操作: 候補をタップで選択
正解後: 「なぜこの手か」の短い解説 + 不正解の手がダメな理由
例:
  盤面: [局面SFEN]
  候補A: 「△同銀」
  候補B: 「△3三角」
  正解: B
  Why: 「同銀は飛車で取り返されて駒損。角を引けば守りつつ反撃できる」
```

## 4. Section末の設計

### Skill Check（review）
- 該当Sectionの問題から7〜10問ランダム出題
- 過去のミス問題を優先
- 60%以上で通過

### Coached Game（coached_game）
- AI対局（強さはSectionに応じて調整）
- コーチが要所で局面を止める：
  - 「ここは大事な場面じゃ。よく考えて」
  - 「この駒、取って大丈夫か？」
  - 「王が危ないぞ。守りを考えよう」
- 局面を止める条件：
  - プレイヤーがただで駒を取られそう
  - 詰みチャンスを逃しそう
  - 悪手を指しそう

### Post-Game Reflection（post_game_reflection）
- 対局終了後に3枚のカードを表示：
  1. **よかった手** 🟢 — 盤面 + 「この手はよかった。なぜなら…」
  2. **危なかった手** 🔴 — 盤面 + 「ここは危なかった。こうすればよかった」
  3. **次の約束** 🎯 — 「次から〇〇を意識しよう」

## 5. 復習の3層構造

### Layer 1: レッスン内復習
- レッスンの最後にミスした問題を自動再出題
- 再出題は同じ問題をそのまま（間を置かずに復習）

### Layer 2: デイリー復習
- 毎日アプリ起動時に3〜5問
- 間隔反復で出題タイミングを決定：
  - 初回正解: 1日後
  - 2連続正解: 3日後
  - 3連続正解: 7日後
  - 間違い: 即座にキューに戻す
- 同じ概念を**別の局面**で出す（丸暗記防止）

### Layer 3: Section復習
- Section末のSkill Check
- 通過後もロードマップ上に「復習推奨」バッジが出る（最後のクリアから7日後）

## 6. 動機づけ設計

### ストリーク
- 1日1レッスンで継続
- 7日連続: ボーナスXP 2倍
- 30日連続: ボーナスXP 3倍
- ストリークフリーズ: 月2回まで（無料）

### XPと段位
- レッスン完了: 10〜30 XP（ミス数で変動）
- coached_game完了: 50 XP
- 累計XPで段位表示（30級→1級→初段…）

### ライフの設計思想
- レッスン中: ♥5つ。0で失敗→再挑戦
- **復習・再挑戦は無料**（ライフ消費なし）
- 詰まった時: 「失敗」ではなく「もう一度一緒に見よう」
- **課金でライフ無制限は避ける**（学習を罰しない）

### デイリーチャレンジ
- 毎日1問のランダム問題（ロードマップ外）
- 苦手スキルから優先出題
- 正解: ボーナスXP

## 7. レッスン種別のデータモデル

### 既存LessonStepの拡張

```typescript
type LessonStepType =
  | "move"           // 駒を動かす（guided_move / find_move共用）
  | "tap_square"     // マスをタップ
  | "quiz"           // 選択式クイズ
  | "compare";       // 比較判断（Why step）

type LessonStep = {
  id: string;
  type: LessonStepType;
  board_sfen: string;
  instruction: string;
  coach_text?: string;

  // move用
  correct_move?: { from: Position; to: Position };
  guided?: boolean;          // true=ヒント付き（guided_move）

  // tap_square用
  correct_square?: Position | Position[];
  result_sfen?: string;

  // quiz用
  quiz_options?: string[];
  quiz_answer?: number;

  // compare用（新規）
  compare_options?: CompareOption[];
  compare_answer?: number;
  why_text?: string;         // 正解後に表示する「なぜ」の解説

  // 共通
  success_text?: string;
  fail_text?: string;
  hint_after_failures?: number;  // N回失敗後にヒント表示（デフォルト2）
};

type CompareOption = {
  label: string;              // "△同銀"
  description?: string;       // 短い説明
  move?: { from: Position; to: Position };  // 盤面上にプレビュー表示（任意）
};
```

### レッスンメタデータの拡張

```typescript
type LessonType =
  | "learn"
  | "guided_move"
  | "find_move"
  | "compare"
  | "review"
  | "coached_game"
  | "post_game_reflection";

type LessonData = {
  id: string;
  title: string;
  type: LessonType;           // 新規: ロードマップアイコン用
  section_id: string;          // 新規: Section紐付け
  unit: string;
  steps: LessonStep[];
  reward_xp: number;
  estimated_minutes?: number;
};
```

### 振り返りカードのデータモデル（新規）

```typescript
type ReflectionCard = {
  type: "good" | "bad" | "next";
  board_sfen: string;
  move?: { from: Position; to: Position };
  title: string;              // "よかった手" / "危なかった手" / "次の約束"
  description: string;        // 解説テキスト
};
```
