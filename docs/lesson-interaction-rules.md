# レッスン操作ルール（全レッスン共通）

このドキュメントは全レッスンで共通の操作ルールを定義します。
basics_pawn および u1_what_is_shogi で確立・テスト済み。

## 駒の選択と移動

### 盤上の駒
| 操作 | 結果 |
|---|---|
| 先手の駒をタップ | その駒を選択（1.15倍に拡大） |
| 選択中に同じ駒をタップ | 選択解除 |
| 選択中に別の先手駒をタップ | 選択切り替え |
| 選択中に合法手のマスをタップ（正解） | 駒が移動、正解判定 |
| 選択中に合法手のマスをタップ（不正解） | 駒が移動、不正解判定（ライフ-1） |
| 選択中に非合法手のマスをタップ | 選択解除（ペナルティなし） |

### 持ち駒
| 操作 | 結果 |
|---|---|
| 持ち駒をタップ | その駒を選択（1.15倍に拡大） |
| 選択中に同じ持ち駒をタップ | 選択解除 |
| 選択中に空きマスをタップ（正解） | 駒を打つ、正解判定 |
| 選択中に空きマスをタップ（不正解） | 駒を打つ、不正解判定（ライフ-1） |
| 選択中に駒があるマスをタップ | 選択解除（ペナルティなし） |

### 盤面外タップ
| 操作 | 結果 |
|---|---|
| 吹き出し・おじいちゃん・背景をタップ | 選択解除 |

## 合法手判定（moveValidation.ts）

- 全9種の駒 + 成り駒の移動パターンを判定
- 飛車・角・香車の経路ブロック判定あり
- 自分の駒がいるマスには移動不可
- 盤面外（0-8の範囲外）には移動不可

## 自動応手（auto_response）

- プレイヤーが正解手を指した後、0.8秒（AUTO_RESPONSE_MS）後に相手が自動で指す
- **待機中はプレイヤーの全操作をブロック**（waitingAutoResponse フラグ）
- 待機中は駒選択・持ち駒選択・盤面タップ全て無視

## マルチターン（1ステップ内で複数手）

- `second_move` で2手目を定義可能
- フロー: プレイヤー1手目 → 相手auto_response → プレイヤー2手目 → 相手second_auto_response → 正解判定
- 1手目と2手目の間に `coachOverride` で吹き出しテキストを一時表示
- `second_arrows` で2手目用の矢印を表示

## 矢印

- 盤面座標: `[row, col]`（0-indexed）
- 持ち駒: `"hand_ki"` 等の文字列
- 矢印は正解手を指した瞬間に非表示（boardOverride設定時）
- 2ターン目の矢印は coachOverride が null になった時点で非表示
- フィードバック表示中は非表示

## 正解後の表示

- 正解: フッターが下からスライドイン「正解！次へ進もう！」
- auto_responseがある場合: 正解直後はフッター非表示 → 0.8秒後に相手応手 → フッター表示
- マルチターンの場合: 全ターン完了後にフッター表示

## 不正解後の表示

- 不正解の駒移動を boardOverride で表示
- 0.7秒（CLEAR_FEEDBACK_MS）後にフィードバック消去 + 選択解除
- 不正解テキスト表示: 現在無効化（将来コーチ吹き出しで表示予定）

## 座標系

```
将棋座標 → 配列インデックス:
  筋（列）: col = 9 - 筋    例: 5筋 → col=4, 2筋 → col=7
  段（行）: row = 段 - 1    例: 7段 → row=6, 1段 → row=0

例:
  57 (5筋7段) → [6, 4]
  26 (2筋6段) → [5, 7]
  52 (5筋2段) → [1, 4]
```
