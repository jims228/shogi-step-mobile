# YouTube マーケティング戦略

## 目標
- 月額290円サブスク + 広告で月売上1万円以上
- 必要課金者数: 約35人
- 必要DL数: 約1,200（課金率3%想定）

---

## フェーズ1: α版テスト（リリース3日後）

### 目的
- 実際のユーザーからフィードバックを得る
- 致命的な問題を発見・修正する

### 依頼するYouTuber: 1名
- **条件:**
  - 登録者1万〜5万の将棋系チャンネル
  - 初心者向けコンテンツを出している
  - 「将棋 初心者」「将棋 入門」で検索して出てくる
  - 視聴者層が初心者〜級位者

- **依頼内容:**
  - アプリを1週間使ってもらう（課金は不要、全機能開放）
  - 良い点・悪い点を率直にフィードバックしてもらう
  - 動画にする必要はない（DM/メールでOK）
  - 「もし気に入ったら後日紹介動画をお願いしたい」と伝える

- **依頼文テンプレート:**
  ```
  突然のDM失礼します。
  将棋初心者向けの学習アプリ「将棋ステップ」を個人開発しています。
  Duolingoのような体系的レッスンで、駒の動きから1手詰めまで
  ステップバイステップで学べるアプリです。

  ○○さんの初心者向け動画をいつも拝見しており、
  ぜひ率直なフィードバックをいただきたくご連絡しました。

  1週間ほどお試しいただき、
  良い点・改善点を教えていただけないでしょうか？
  （動画にしていただく必要はありません）

  もし気に入っていただけたら、
  後日紹介動画のご相談もさせていただければ幸いです。

  よろしくお願いいたします。
  ```

## フェーズ2: β版ストア公開（α版+1週間）

### 目的
- フィードバック反映後、ストアに正式公開
- レビュー・評価を集め始める

### やること
- α版フィードバックの修正を反映
- Google Play + App Store に公開
- ストア掲載情報の最適化:
  - タイトル: 「将棋ステップ - 初心者向け将棋レッスン」
  - キーワード: 将棋 初心者 / 将棋 学習 / 将棋 入門 / 将棋 アプリ
  - スクリーンショット5枚（レッスン画面、ロードマップ、コーチ、詰め将棋、クイズ）
  - 説明文に「Duolingoのように学べる」を明記

## フェーズ3: 正式プロモーション（β版+数日〜2週間）

### 目的
- YouTuber経由でDL数を一気に増やす
- 月1,200DL達成 → 課金35人 → 月売上1万円

### 依頼するYouTuber: 3名

#### ターゲットYouTuberの条件
| 条件 | 理由 |
|------|------|
| 登録者1万〜10万 | 大きすぎると依頼が通らない、小さすぎると効果薄 |
| 初心者向けコンテンツ | アプリのターゲットと一致 |
| 週1回以上投稿 | アクティブなチャンネル |
| コメント欄が活発 | 視聴者がアクティブ |

#### 依頼の種類（3パターン）
1. **レビュー動画** — アプリを紹介する専用動画（最も効果的）
2. **動画内で紹介** — 通常動画の冒頭/末尾で30秒紹介
3. **概要欄リンク** — 動画の概要欄にアプリリンクを掲載

#### 報酬の考え方
- **無料で依頼**: 個人開発であることを伝え、好意で紹介してもらう
- **成果報酬**: 紹介リンク経由のDL数に応じた報酬（1DL=10円など）
- **固定報酬**: 1動画あたり5,000〜10,000円（予算がある場合）
- **おすすめ**: 最初は無料依頼。「個人開発の将棋アプリを応援してほしい」スタンス

#### 依頼文テンプレート（紹介動画用）
```
○○さん、いつも動画を楽しく拝見しています。

将棋初心者向けの学習アプリ「将棋ステップ」を
個人開発しました。

Duolingoのようにステップバイステップで
駒の動きから詰将棋まで学べるアプリです。

○○さんの視聴者さんにもお役に立てるのではと思い、
もしよろしければ動画でご紹介いただけないでしょうか？

全機能を無料でお使いいただけるコードもお渡しできます。

Google Play: [リンク]
App Store: [リンク]

よろしくお願いいたします。
```

## 並行施策: SNS + 記事

- **頻度**: 週2-3回
- **投稿内容**:
  - 1手詰め問題の画像（アプリ画面キャプチャ）
  - 開発進捗・アップデート情報
  - 将棋ニュースへの反応
- **ハッシュタグ**: #将棋 #将棋初心者 #将棋アプリ #詰将棋
- **目標**: フォロワー500人（3ヶ月）

### note記事（1本）
- タイトル案: 「将棋初心者向けアプリを個人開発した話」
- 内容: 開発の動機、Duolingo×将棋のコンセプト、技術スタック
- 効果: 開発者コミュニティからの流入 + バズ可能性

## リスクと対策

| リスク | 対策 |
|--------|------|
| YouTuberに断られる | 5人以上に同時依頼、1人でも受けてもらえればOK |
| レビューで低評価 | α版テストで致命的問題を事前に潰す |
| DL後の離脱率が高い | オンボーディング改善、プッシュ通知でリテンション |
| 競合アプリの出現 | 先行者優位を活かし、コンテンツ量で差別化 |
| SFENの間違い | YouTuber依頼前に全レッスンを手動テスト |
