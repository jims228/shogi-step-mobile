# 将棋ステップ カリキュラム仕様書 v3

## 設計思想

### 核となる考え方

1. **プレイヤーの仕事順に教える** — 駒図鑑（歩→金→銀→…）ではなく、「勝ち負けを知る→駒を動かす→将棋らしいルールを覚える→勝てるようになる」の順で組む。学習者が「今なぜこれを学ぶのか」を常に感じられる。

2. **全レッスンに操作と判断がある** — 説明だけのステップは存在しない。必ず盤面をタップするか駒を動かすか選択肢を選ぶ。

3. **Why stepを重視する** — 「正解はこれ」で終わらせず、「なぜ他の手はダメなのか」を必ず扱う。これがDuolingo Chess との最大の差別化ポイント。

4. **Unit末は復習だけで終わらせない** — 復習テスト→ガイド対局→振り返り3カードの流れで、「学んだ」ではなく「少し指せるようになった」を感じさせる。

5. **復習は3層** — レッスン内ミス復習（即座）、デイリー弱点復習（間隔反復）、Unit末復習（まとめテスト）。同じ概念を別の局面で出し、丸暗記を防ぐ。

6. **ライフは罰ではなく集中の演出** — 復習・再挑戦は無料。「失敗」ではなく「もう一度一緒にやろう」。

### レッスン種別の定義

| コード | 名前 | 内容 |
|---|---|---|
| `learn` | 概念導入 | コーチが概念を見せる。必ず操作付き |
| `guided_move` | ガイド付き | 指示通りに駒を動かす。ヒント付き |
| `find_move` | 自力発見 | ヒントなしで最善手を探す |
| `compare` | 比較判断 | 2〜3候補を比較。Why step |
| `review` | 復習 | 過去のミス＋弱点を混合出題 |
| `coached_game` | ガイド対局 | コーチが要所で止めて助言する対局 |
| `reflection` | 振り返り | 対局後の3カード（良い手/危ない手/次の約束） |

### 1レッスンの標準構造（5〜7ステップ、3〜5分）

```
1. 目標提示 + 盤面タップで確認（learn的な操作付き導入）
2. ガイド付きで1回やる（guided_move）
3. 自力で1回やる（find_move）
4. Why step — 比較問題（compare）
5. もう1回自力（find_move、別局面）
6. 簡単な成功体験で終わる（guided_move）
※ ミスした問題は末尾に自動再出題
```

## Unit末の構成パターン

### パターンA: 知識Unit（Unit 1, 4, 5, 6, 8）
```
→ review（5〜7問、ミス優先）
```
初期のUnitやスキル特化Unitでは復習だけ。対局は入れない。

### パターンB: 実践Unit（Unit 2, 3, 7）
```
→ review（5〜7問）
→ coached_game（5〜10分）
→ reflection（3カード）
```
ある程度駒を動かせるようになったUnitでは、復習＋対局＋振り返り。

### パターンC: 総合Unit（Unit 9）
```
→ review（総合10問）
→ coached_game × 3（段階的に難易度上昇）
→ reflection × 3（各対局後）
```
最終Unitは実戦ラッシュ。

## 復習の3層構造

### Layer 1: レッスン内
- ミスした問題をレッスン末に自動再出題
- 同じ問題をそのまま（即時復習）

### Layer 2: デイリー
- アプリ起動時に3〜5問
- 間隔反復: 1日→3日→7日→14日
- 同じ概念を**別の局面**で出す

### Layer 3: Unit末
- review レッスンとして明示的にロードマップに配置
- ミス問題を優先出題
- 60%以上で通過
