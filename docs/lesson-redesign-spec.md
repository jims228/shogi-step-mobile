# 将棋学習アプリ レッスン再設計仕様書

## 1. Duolingo Chess 調査結果

### 1-1. 公式に確認できる事実 [CONFIRMED]

- **コース構成**: 75%がパズル、25%がミニマッチ＋フルマッチ。総計55時間以上
- **目標到達レベル**: 完全初心者 → Elo 1500相当（中級）
- **コース構造**: Section > Unit > Lesson のツリー。Sectionごとにレビュー（復習テスト）
- **復習**: 独自のspaced repetitionアルゴリズムで過去のタクティクスを最適間隔で再出題
- **レッスンの長さ**: 1レッスン3〜5分。15分/日を最適利用時間として設計
- **コーチキャラ**: Oscar（自信過剰で分析的な性格のチェスコーチ）
- **学習5原則**: ①やって学ぶ ②AI個別化 ③体系的カリキュラム ④ゲーミフィケーション ⑤キャラで感情接続
- **初心者適応**: 開始時にレベルを聞いて学習パスを調整

### 1-2. レビュー等から推測できること [REPORTED]

- **レッスン種別（ロードマップ上のアイコンで区別）**:
  1. **理論レッスン**（星アイコン）— コーチが概念を教える
  2. **ベストムーブ**（ダンベルアイコン）— 最善手を見つけるパズル
  3. **ミニマッチ**（騎士アイコン）— 90秒制限の駒取りドリル
  4. **フルマッチ**（ルークアイコン）— 15〜20分のAI対局
  5. **復習**（トロフィーアイコン）— Section末のチェックポイント

- **レッスン内の進行**: ガイド付き指示（「ここにビショップを動かして」）→ 自由課題（「2手詰めを見つけて」）へ段階的に移行
- **エラー処理**: 同じ手で繰り返し詰まると矢印で正解をガイド。間違いの後もプログレスバーが少し進む
- **ミニマッチ詳細**: 1〜2種の駒だけで敵駒を捕獲。スコア制（5点=☆1、20点=☆2、40点=☆3）。Unit 4以降に登場
- **レッスン内構造（言語版の参考）**: 15問程度で構成。序盤は選択式→中盤は制約付き→終盤は自由回答→最後は簡単な問題で成功体験

### 1-3. 不明で断定できないこと [UNKNOWN]

- Section/Unitの総数
- spaced repetitionの具体的アルゴリズム（間隔の計算式）
- AI対局エンジンの強さ調整の具体的パラメータ
- レッスン後に復習で再出題される具体的条件

## 3. 将棋版レッスン再設計

### 3-1. 設計思想

Duolingo Chessの**学習原理**を取り入れつつ、**将棋固有の教育体系**（手筋・囲い・定跡・詰将棋）に合わせて再構成する。UIは和のデザイン言語で独自性を出す。

### 3-2. レッスン種別一覧

| 種別 | アイコン案 | 内容 | 1回の長さ |
|---|---|---|---|
| **解説（learn）** | 📖 巻物 | コーチが概念を教える。盤面を見せながら説明→簡単な確認問題 | 2〜4分 |
| **手筋（drill）** | ⚔️ 刀 | 最善手パズル。正しい一手を見つける | 3〜5分（5〜8問） |
| **詰将棋（tsume）** | 🏯 城 | 詰将棋（1手〜5手詰め）。持ち駒使用あり | 3〜5分（3〜5問） |
| **ミニ対局（mini）** | ♟️ 駒 | 制限時間60秒。特定の駒で敵駒を取る/王手する | 60〜90秒 |
| **実戦（match）** | ⚔️ 二刀 | AI対局（10〜15分）。段階的に強くなる | 10〜15分 |
| **復習（review）** | 🎯 的 | Section末のチェックポイント。過去の問題を混合出題 | 3〜5分 |

### 3-3. 1レッスンの共通テンプレート

```
┌─────────────────────────────────┐
│  プログレスバー  ♥♥♥♥♥  ✕閉じる │  ← ヘッダー
├─────────────────────────────────┤
│                                 │
│  コーチ吹き出し（説明/フィード   │  ← 対話エリア
│  バック）                       │
│                                 │
├─────────────────────────────────┤
│                                 │
│         将 棋 盤 面              │  ← インタラクションエリア
│        （9x9 or 部分盤）        │
│                                 │
├─────────────────────────────────┤
│  [選択肢A] [選択肢B] [選択肢C]  │  ← クイズ時のみ表示
├─────────────────────────────────┤
│         [ 次へ ]                │  ← フッター
└─────────────────────────────────┘
```

**レッスン内ステップの流れ（7〜10ステップ）:**

1. **導入**（explain）: コーチが概念を説明。盤面表示あり
2. **確認1**（tap_square）: 「この駒が動ける場所はどこ？」→ マスをタップ
3. **確認2**（move）: 「王手をかけてみよう」→ 駒を移動
4. **応用1**（move）: ヒントなしで最善手を見つける
5. **クイズ**（quiz）: 「この局面で正しいのは？」→ 選択式
6. **応用2**（move）: より難しい局面で同じパターンを使う
7. **まとめ**（explain）: コーチがポイントを整理
8. **仕上げ**（move/tap_square）: 簡単な問題で成功体験 ← **peak-end rule**

**フィードバックルール:**
- 正解: 緑ハイライト + 効果音 + コーチ褒めセリフ → 0.6秒後に自動進行
- 不正解: 赤ハイライト + 効果音 + ライフ-1 + コーチヒントセリフ → 0.7秒後にクリア
- 2回連続不正解: 矢印ガイドで正解を表示
- ライフ0: ゲームオーバー → 「もう一度挑戦」ボタン

### 3-5. 復習の仕組み

```
復習トリガー:
  1. Section末の復習レッスン（必須ゲート）
  2. 間隔反復による自動挿入（ロードマップ上に「復習推奨」バッジ表示）
  3. 間違えた問題の再出題（同一レッスン内 + 次回レッスン冒頭）

間隔反復のルール:
  - 初回正解: 1日後に再出題候補
  - 2回連続正解: 3日後
  - 3回連続正解: 7日後
  - 間違えた: 即座に候補に戻す

復習レッスンの構成:
  - 過去のSection全体からランダムに7〜10問抽出
  - 間違えた問題を優先的に出題
  - 全問正解でなくても通過可能（60%以上で合格）
```

### 3-6. ミニ対局の仕組み

```
ミニ対局（mini）:
  - 制限時間: 60秒
  - ルール: 特定の駒（1〜2種）だけを使い、目標を達成する
  - 目標例:
    - 「飛車で歩を5枚取れ」
    - 「桂馬で金を取れ」
    - 「銀2枚で王手をかけろ」
  - スコア: 目標達成数に応じて☆1〜3
  - 登場タイミング: Section 1 の終盤（レッスン8）から

実戦（match）:
  - Section 4以降に登場
  - AI対局（強さ調整可能: 10級→5級→1級→初段）
  - 持ち時間: 10分（切れ負け）
  - 勝利条件: 詰み or 相手の投了
  - 敗北してもロードマップは進行可能（ただし☆1止まり）
```

### 3-8. UI/UXで参考にしてよい原理

| 原理 | 将棋版での適用 |
|---|---|
| 3〜5分の一口サイズレッスン | 7〜10ステップ、各ステップ20〜30秒 |
| 即時フィードバック | 正解=緑+音、不正解=赤+音+ヒント |
| プログレスバー | レッスン上部に常時表示 |
| ライフシステム | ♥5つ。0で失敗。時間経過or再挑戦で回復 |
| ロードマップ型進捗 | 蛇行パスにレッスンノード |
| 最後を成功で終える | 最終ステップは簡単な問題 |
| 間違えた問題の再出題 | 同一レッスン内で再出題 + 次回復習に追加 |
| コーチキャラの感情表現 | 正解時に喜ぶ、不正解時に励ます |
| セクション末の復習ゲート | 理解度確認 + 間隔反復のトリガー |
| 難易度の段階的上昇 | 選択式 → タップ → 駒移動 → 自由回答 |

## 4. 実装しやすいデータモデル案

### 4-1. コース構造

```typescript
// コース全体
type Course = {
  sections: Section[];
};

type Section = {
  id: string;           // "section-1"
  title: string;        // "将棋の世界へ"
  lessons: LessonMeta[];
};

type LessonMeta = {
  id: string;           // "learn-pawn-movement"
  title: string;        // "歩の動き"
  type: LessonType;     // "learn" | "drill" | "tsume" | "mini" | "match" | "review"
  section_id: string;
  order: number;
  prerequisites: string[];  // 前のレッスンID
};
```

### 4-2. レッスンデータ（既存LessonDataの拡張）

```typescript
type LessonData = {
  id: string;
  title: string;
  type: LessonType;
  section_id: string;
  steps: LessonStep[];
  reward_xp: number;
  estimated_minutes: number;  // 目安時間
};

// 既存のLessonStepを維持しつつ拡張
type LessonStep = {
  id: string;
  type: "explain" | "move" | "tap_square" | "quiz" | "multi_move";
  board_sfen: string;
  highlights?: Position[];
  instruction: string;
  coach_text?: string;
  correct_move?: { from: Position; to: Position };
  correct_square?: Position;
  quiz_options?: string[];
  quiz_answer?: number;
  success_text?: string;
  fail_text?: string;
  hint_after_failures?: number;  // N回失敗後にヒント表示（デフォルト2）
  // 新規: multi_move用（詰将棋の連続手順）
  correct_sequence?: { from: Position; to: Position }[];
  auto_response?: { from: Position; to: Position };  // AI側の応手
};

type LessonType = "learn" | "drill" | "tsume" | "mini" | "match" | "review";
```

### 4-3. 進捗データ（既存MobileProgressの拡張）

```typescript
type MobileProgress = {
```
